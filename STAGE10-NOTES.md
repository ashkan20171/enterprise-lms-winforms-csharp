# AshkanLMS Stage 10 — Enterprise UX & Global Direction

## Global FA/EN direction
- Persian: recursive RTL for all forms/controls, sidebar physically right.
- English: recursive LTR for all forms/controls, sidebar physically left.
- Dynamic pages are re-applied after every navigation.
- DataGridView, FlowLayoutPanel, ListView, TreeView, text inputs and dialogs follow direction.

## New portfolio/enterprise modules
- Global Search across students, courses and instructors
- Risk & Progress Center
- Course 360
- Instructor Workspace
- Report Center with UTF-8 CSV export
- Security & Access Center
- Role-aware navigation (Instructor does not receive Admin-only security/audit/user menus)
- Existing Student 360, Calendar, Notifications, Audit, bilingual backgrounds retained

## Build target
.NET Framework 4.8 / Windows Forms / Visual Studio
